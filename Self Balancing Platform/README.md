# Self Balancing Platform

## Overview
A dynamic self-balancing platform designed to maintain spatial stability using active feedback. The mechanism utilizes two independent servo motors to control the **roll** and **pitch** motions of the platform. The stability control loop is driven by a custom **PID controller**, which was carefully fine-tuned to ensure smooth, rapid, and precise balancing responses to disturbances.
